# Contributing to Eiger's Portfolio

Thank you for checking out this repo. Here is how you can help:

- Open an issue if you have a new idea for a security tool or a tip.
- Suggest improvements to the README or project descriptions.
- Add more cybersecurity tips to `projects/cyber_security_tips.py`.
- Help make the code easier to understand for beginners.
- Share this repo with friends who want to learn security.

## What I am looking for
- clear ideas for tools that help people stay safe online
- beginner-friendly improvements
- documentation updates and better instructions

## How to contribute
1. fork this repository
2. make your changes in a new branch
3. submit a pull request
4. I will review and add it to the portfolio
