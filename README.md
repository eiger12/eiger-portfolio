# Eiger's IT & Cybersecurity Portfolio

## Latest release
- May 31, 2026: added the URL Security Checker and new contribution guide.
- This portfolio now includes 4 beginner-friendly security tools.

## Projects
### 1. Password Strength Checker
A quick Python tool that checks passwords and explains what makes them weak.

### 2. Strong Password Generator
Generates a random password with letters, numbers, and symbols.

### 3. Cybersecurity Tips Assistant
A small helper that gives safety tips for passwords, accounts, browsing, and devices.

### 4. URL Security Checker
Checks whether a link uses HTTPS and gives simple advice for safer browsing.

### 5. Learning Notes
A place to write ideas, lessons, and next project plans.

## Run the tools
1. Open `eiger-portfolio` in VS Code.
2. Open a terminal.
3. Run one of these commands:
   - `python projects/password_strength_checker.py`
   - `python projects/strong_password_generator.py`
   - `python projects/cyber_security_tips.py`
   - `python projects/url_security_checker.py`
